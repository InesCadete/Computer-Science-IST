# 🌟 **ASA - Analysis and Synthesis of Algorithms** 🌟

---

## 📌 **Course Overview**

This course delves into the **analysis and synthesis of algorithms**, covering:

- **Sorting algorithms** and fundamental **data structures**:
  - Lists, Stacks, Queues, Priority Queues, Hash Tables, Trees
- **Algorithmic techniques**:
  - Amortized Analysis
  - Graph Algorithms (Shortest Paths, Minimum Spanning Trees, Maximum Flows)
  - Linear Programming (Simplex Algorithm)
  - Dynamic Programming, Greedy Algorithms
  - String-Matching Algorithms
  - Computational Complexity (P, NP, NP-complete, NP-hard problems)

Each project includes a **detailed report (PDF)** explaining the problem-solving approach and analyzing the complexity of each algorithm stage.

---

## 📝 **Concepts Applied in Each Project**

### 🚀 **Project 1: Tabulation**
- **Concept**: Breaking the problem into **simpler subproblems** and **storing results** to reuse (Dynamic Programming)
- **Key Idea**: Avoid redundant calculations by storing solutions to subproblems

### 🔗 **Project 2: Graphs & Longest Path**
- **Concepts**: Graph theory, **Kosaraju-Sharir algorithm** (for strongly connected components)
- **Techniques**: Depth-First Search (DFS), Directed Acyclic Graphs (DAGs)

### 📊 **Project 3: Linear Programming**
- **Concept**: Optimization using **decision variables**
- **Application**: Maximizing a result (e.g., **profit**) using **Linear Programming (Simplex Algorithm)**

---

🎯 **This course provides a solid foundation in algorithm design and computational complexity, essential for tackling real-world optimization and decision-making problems!** 🚀
