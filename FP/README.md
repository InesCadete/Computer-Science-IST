# 🌟 **FP- Fundamentals of Programming ** 🌟

---

## 📌 **Course Overview**

This course introduces the **core concepts of programming**, focusing on fundamental principles, syntax, and problem-solving techniques. Topics covered include:

- **Computers, algorithms, and programming languages**.
- **Basic programming constructs**:
  - Elementary data types, variables, and assignments.
  - Input/output operations.
  - Control structures: **sequencing, selection, and repetition**.
- **Functions and procedural abstraction**.
- **Data structures**:
  - Strings, lists, tuples, dictionaries, and files.
- **Recursion vs. Iteration**.
- **Higher-order functions & Functional Programming**.
- **Abstract data types & Object-Oriented Programming (OOP)**.

Each project includes a **detailed report (PDF)** explaining the problem, methodology, and implementation details.

## 📝 **Concepts Applied in the Projects**

### 📝 **Project 1: Text Manipulation & Basic Python Functions**
- Introduced fundamental **string operations**, list manipulations, and file handling.

### 🦁 **Project 2: Animal Ecosystem Simulation**
