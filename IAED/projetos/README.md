# 💻 **IAED - Introduction to Algorithms and Data Structures** 💻

---

## 📌 **Course Overview**

This course introduces **algorithms and data structures** using the **C programming language**, along with a focus on **algorithm complexity** and efficient data structures. Key topics include:

- **Sorting Algorithms**: Implementing direct sort, selection sort, bubblesort, quicksort, and mergesort.
- **Data Types**: Working with stacks, queues, priority queues, and heaps.
- **Searching Algorithms**: Searching within trees and binary search trees.
- **Dynamic Data Structures**: Understanding linked lists and more advanced structures like binary trees, balanced binary trees, and hash tables.
- **Collision Resolution**: Implementing techniques like chaining, open addressing, and double hashing for efficient hash table management.

By the end of the course, students will gain a solid foundation in C programming and how to implement, optimize, and analyze various algorithms and data structures.

## 📝 **Project Overview**

### 🚍 **Project 1: Basic Public Transportation Management System**

The first project involves developing a **public transportation management system** in C, allowing users to manage **lines**, **stops**, and **links**. The program supports the following commands:

- **`q`**: Quits the program.
- **`c`**: Adds and lists transportation lines.
- **`p`**: Adds and lists stops.
- **`l`**: Adds and lists links between stops.
- **`i`**: Lists intersections between transportation lines.

This system is built using **dynamic data structures** like **linked lists** to represent transportation lines, stops, and their relationships. The project demonstrates basic data manipulation and memory management using C.

---

### 🚀 **Project 2: Extended Public Transportation System**

In the second project, the system is extended with the following additional functionality:

- **`r`**: Removes a line from the system.
- **`e`**: Eliminates a stop from the system.
- **`a`**: Deletes all stored data (lines, stops, and links).

These extensions introduce **advanced memory management** and additional user interaction capabilities, enabling a more comprehensive transportation system management.

## 🧠 **Key Concepts Applied**

### 🔀 **Sorting Algorithms**
- **Sorting Techniques**: Implementation of various sorting algorithms like quicksort and mergesort.
- **Algorithm Complexity**: Understanding and analyzing the time and space complexity of sorting algorithms.

### 📚 **Data Structures**
- **Stacks, Queues, Priority Queues, and Heaps**: Using these fundamental data structures for efficient data management.
- **Binary Trees**: Implementing basic binary trees for efficient searching.
- **Balanced Binary Trees**: Ensuring optimal search times through balanced structures.
- **Hash Tables**: Implementing hash tables with collision resolution techniques like chaining, open addressing, and double hashing.

### 🧑‍💻 **Memory Management**
- **Dynamic Memory Allocation**: Using `malloc()` and `free()` for managing memory efficiently during the program's execution.
