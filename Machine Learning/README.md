## 📌 **Course Overview**

The **Machine Learning** course provides a comprehensive introduction to the field of machine learning, focusing on the core principles and techniques used in modern machine learning systems. The course explores the following topics:

1. **Machine Learning Concept**: Introduction to supervised learning and its applications.
2. **Linear Regression**: Understanding quadratic cost, normal equations, and regularization techniques for regression tasks.
3. **Optimization**: Methods to optimize machine learning models.
4. **Evaluation and Generalization**: Understanding the importance of train, validation, and test sets, and the concept of cross-validation.
5. **Neural Networks**: Exploring multilayer perceptrons, cost functions, training methods, back-propagation, and convolutional networks.
6. **Data Classification**: Analyzing data classification methods with a focus on the optimal classifier, such as the Bayes classifier.
7. **Linear Classifiers**: Exploring one-hot encoding, logistic regression, and linear discriminant analysis.
8. **Support Vector Machines**: Studying hard margin, soft margin, and non-linear classifiers.
9. **Decision Trees and Random Forests**: Learning about impurity measures, the ID3 algorithm, bagging, and random subspace methods.
10. **Feature Selection and Extraction**: Techniques for selecting and extracting important features for machine learning models.

Through a series of hands-on projects, students will implement and explore various machine learning algorithms, from classification and regression to neural networks and clustering techniques.

## 📝 **Project Overview**

### 💡 **Jupyter Notebooks Projects**

Throughout the course, small projects are completed in Python using **Jupyter Notebooks**, each focused on specific aspects of machine learning. These projects allow students to apply the concepts learned in class to real-world datasets.

The following topics are covered in the Jupyter Notebooks:

1. **Data Exploration**:
   - Exploring datasets to understand the distribution and relationships between features.
   - Used dataset: `iris.csv`, `iris.json`

2. **Decision Trees**:
   - Implementing decision trees to solve classification problems.
   - Analyzing the ID3 algorithm and the concept of impurity.
   - Used dataset: `small_titanic.csv`

3. **Evaluation and Bayes Classifier**:
   - Implementing the Bayes classifier and evaluating its performance.
   - Understanding the concept of cross-validation.

4. **Regression**:
   - Implementing linear regression, understanding cost functions, and normal equations.
   - Evaluating regression models.

5. **Classification**:
   - Applying classification algorithms to datasets and evaluating their performance.
   - Exploring logistic regression and classification metrics.

6. **Clustering**:
   - Implementing clustering algorithms such as K-means clustering.
   - Evaluating clustering results.

7. **PCA (Principal Component Analysis)**:
   - Reducing dimensionality of datasets using PCA for better performance and visualization.
