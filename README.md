## 📂 Repo Rules/Organization 🗂️

Each **discipline/course**/"**cadeira**" that has coding assignments or projects will have its own **folder**. 🗂️

### 🧑‍🏫 **Structure:**

- **Lab/Practical Classes** 🛠️: All lab/practice classes will be under a subfolder called **LAB**. This includes all **question papers** and related materials, stored in the same directory as the answers. 📃 (e.g. IAED/FP).

- **Projects** 🚀: All projects will be in folders named **Proj** or **Proj@**, where "@" represents the project number. If available, **automatic tests** will be kept **zipped** for future reference. 🧪 (e.g. IAED/Proj1).

- **Content Tracker** 📈: If a content tracker was used (e.g. a history of progress on a project), it will be **archived** (usually **zipped**) but also **committed** to the repo in chronological order. If shared folders were used, the files will be committed by **branch** and then merged to the main branch. 🔄

- **File Naming and Numbering Convention** 🔢:
  - Folder numbers should have the same number of digits as the largest folder number in use (e.g. for 3 folders, name them `01/`, `02/`, `03/`; for 12 folders, use `01/`, `02/`, ..., `12/`). 😎
  - If the course/class book 📖 is available, it will be placed in the folder named after the course (e.g. FP/Programacao em Python; LP/Logica e Raciocinio). 📚
