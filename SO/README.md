# 🖥️ **Operating Systems** 🖥️

## 📌 **Course Overview**
This course covers the **fundamentals of operating systems**, including:
- **Processes, threads, and concurrency**: Synchronization techniques and shared memory.
- **Inter-process communication**: Mechanisms such as FIFOs, signals, and message passing.
- **OS Kernel**: Multitasking, scheduling, and process dispatching.
- **Virtual memory**: Paging, segmentation, and memory management algorithms.
- **File systems**: Structure, organization, and evolution.
